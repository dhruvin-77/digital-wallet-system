# Project Statement

## Problem Statement

Managing common digital wallet activities through separate systems can be inconvenient for users. There is a need for a simple application that combines basic wallet operations such as account management, money handling, transfers, bill payments, and transaction tracking in one place.

The Digital Wallet System addresses this problem by providing a console-based Java application that allows users to perform these operations through a structured menu-driven interface.

## Scope of the Project

The project focuses on simulating the core functions of a digital wallet in an educational environment. The system supports user registration and login, wallet creation, balance management, money transfers, beneficiary management, bill payments, transaction history, and statement generation.

The project also demonstrates Java programming concepts including object-oriented programming, exception handling, collections, file I/O, JDBC, SQLite, multithreading, synchronization, interfaces, inheritance, abstraction, and polymorphism.

The system does not connect to real banking networks, payment gateways, or utility providers.

## Target Users

The intended users of the system are:

- Students learning Java programming
- Users testing basic digital wallet concepts
- Developers studying object-oriented application design
- Academic evaluators reviewing Java programming concepts

## High-Level Features

- User registration and PIN-based login
- Input validation
- Wallet creation and balance checking
- Add money and withdraw money
- Money transfer between users
- Beneficiary management
- Electricity, water, mobile, internet, and gas bill payment simulation
- Transaction history
- Wallet statement export
- Persistent data storage using file I/O
- SQLite database operations using JDBC
- Exception handling
- Multithreading and synchronization demonstration
- Payment processing using interfaces and polymorphism
